1 Create a Free GitHub Account

Go to github.com and click "Sign Up". Use any email address. Choose the Free plan — it includes everything you need.

Username tip: Your GitHub username becomes part of your default URL. Something like yourfemalengineer or joanmelendez works great.

2 Create Your Repository

A "repository" (repo) is just a folder on GitHub that holds your website files. Here's how to create one:

On GitHub.com
1
Click the + icon in the top right → "New repository"
2
Repository name: yourfemalengineer.github.io
⚠️ Important: the name must end in .github.io for GitHub Pages to work
3
Set visibility to Public
GitHub Pages requires public repos on the free plan
4
Check "Add a README file"
This initializes the repo so you can upload files immediately
5
Click "Create repository"

3 Upload Your Website Files

Now upload all your site files to the repo. No code needed — GitHub has a drag-and-drop uploader.

Uploading Files
1
In your new repo, click "Add file" → "Upload files"
2
Unzip your website package and drag all files into the upload area
Upload all files at once — don't upload the zip itself
3
Scroll down and click "Commit changes"
This saves and publishes your files

These are the files you need to upload:

HTMLindex.html
HTMLabout.html
HTMLcontent.html
HTMLspeaking.html
HTMLcontact.html
HTMLmission-control.html
CSSstyle.css
JSshared.js
IMGlogo.png
After uploading: Your site is immediately live at yourfemalengineer.github.io — test it before connecting your domain!

4 Enable GitHub Pages

GitHub Pages is usually auto-enabled for `.github.io` repos, but double-check:

In your GitHub repo
1
Click Settings (top tab in your repo)
2
Scroll down to "Pages" in the left sidebar
3
Under "Source", select Deploy from a branch
4
Branch: main / folder: / (root) → click Save
5
You'll see: "Your site is live at yourfemalengineer.github.io" ✅

5 Add Your Custom Domain in GitHub

Tell GitHub to use your GoDaddy domain instead of the .github.io URL:

Still in GitHub → Settings → Pages
1
Find the "Custom domain" field
2
Type your domain: yourfemalengineer.com (use your actual domain)
3
Click Save
4
Check "Enforce HTTPS" once it appears
This gives you the padlock and secure connection for free
Note: GitHub will add a file called CNAME to your repo automatically. Don't delete it — it's what tells GitHub which domain to use.

6 Point Your GoDaddy Domain to GitHub

This is the final step — you're telling GoDaddy "send visitors to GitHub Pages." Log into your GoDaddy account and find your DNS settings.

In GoDaddy → My Products → Your Domain → DNS
1
Log into godaddy.com and go to "My Products"
2
Find your domain → click "DNS" or "Manage DNS"
3
Delete any existing A records pointing to GoDaddy's servers
These are the old ones — you're replacing them with GitHub's
4
Add these 4 new A records pointing to GitHub:
Type Name Value (GitHub's IP) TTL
A Record@185.199.108.153600
A Record@185.199.109.153600
A Record@185.199.110.153600
A Record@185.199.111.153600
CNAMEwwwyourfemalengineer.github.io600
Wait 15–30 minutes after saving DNS changes. DNS updates take time to spread across the internet. Once done, visiting your domain will load your GitHub Pages site automatically.
✅ You're live! Once DNS propagates, yourfemalengineer.com will show your full custom site — for free, forever, with no ads.

✏️ How to Update Your Site Later

Whenever you want to make changes — update stats, add content, tweak copy — it's simple:

1
Go to your repo on github.com
2
Click the file you want to change (e.g. about.html)
3
Click the pencil icon to edit
4
Make your changes → click "Commit changes"
5
Your site updates live within 60 seconds
Updating your social stats in the Mission Control dashboard: open mission-control.html in GitHub, find the line const STATS={ig:111000,tt:75000... and update the numbers. Commit and you're done.
